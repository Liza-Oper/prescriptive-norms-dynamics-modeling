**Цель: повышение эффективности и скорости разработки нормативных документов (на примере клинических рекомендаций, локальных нормативных актов ЛПУ и т.п.) на базе моделей прескриптивных норм в отдельных нозологиях**

- Постараться найти скрытые паттерны в данных, или доработать существующие
